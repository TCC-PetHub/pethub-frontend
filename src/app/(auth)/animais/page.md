# animais

Catálogo com filtros de espécie, raça, porte, idade, status e organização. `page.tsx` compõe o catálogo dentro de PortalShell. Filtros usam Select compartilhado; dados demonstrativos ficam em `src/features/animals`.

A navegação usa o mesmo organismo TopBar, com o item ativo determinado pela rota e pelo fragmento da URL.
