# Button

Botão compartilhado baseado em `button` nativo, com suporte a atributos HTML e `ref`.

## Props próprias

- `variant`: `primary` (padrão), `secondary`, `tertiary`, `ghost`, `danger`, `danger-ghost` ou `success-ghost`.
- `size`: `md` (padrão) ou `sm`.
- `fullWidth`: ocupa 100% da largura por padrão.
- `isLoading` e `loadingLabel`: desabilitam o botão e mostram o rótulo de carregamento.

Informe `type="submit"` para formulários; o padrão é `button`. Os estilos usam as variáveis CSS do tema.
