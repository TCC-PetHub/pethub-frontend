# Logo

Apresenta a marca PetHub com ícone de pata, nome e subtítulo. A estrutura e os estilos visuais ficam encapsulados no componente.

## Props

- `light`: adapta o texto para fundos escuros.
- `className`: permite acrescentar uma classe ao contêiner.

O posicionamento externo fica a cargo do layout que contém o logo, normalmente `Brand`.
