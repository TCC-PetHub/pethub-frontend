# Toast

Adapta as notificações customizadas do Sonner para os tokens visuais do PetHub.

## Exportações

- `toast.success(message)`
- `toast.error(message)`
- `toast.info(message)`
- `toast.warning(message)`
- `CustomToast`: apresentação customizada usada internamente pelos métodos acima.

O layout raiz precisa montar o `Toaster` do Sonner para exibir as notificações.
