# TopBar

Componente único para todas as telas. A sessão e o perfil vêm do contexto e do armazenamento compartilhado; as páginas não passam variantes, usuários ou listas próprias.

NavigationLinks seleciona exatamente um destino, incluindo páginas internas de animais e adoções e os fragmentos de campanhas e parceiros. O menu da conta contém apenas Sair. Layout, cores e pontos de quebra ficam em styles.ts.
